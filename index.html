ІНСТРУКЦІЯ КОРИСТУВАЧА

1. Головний суддя

Натисніть «ГОЛОВНИЙ СУДДЯ». Ви отримаєте ID кімнати (наприклад ID: 1234) — передайте його суддям та екрану трансляції.

  • Клік на ім'я бійця — редагування імені.
  • + / − біля рахунку — бали головного судді.
  • GAM JUM — попередження (3 = дискваліфікація).
  • JU UI — зауваження (3 = 1 бал штрафу).
  • DOCTOR TIME — пауза для лікаря (2 хв).
  • Клік на таймер — старт/пауза раунду.
  • +10 / −10 сек. — коригування часу.
  • TIME — змінити тривалість раунду.
  • СКИДАННЯ — обнулити матч.

2. Суддя

Натисніть «УВІЙТИ ЯК СУДДЯ», введіть ID кімнати та свій номер (1–4).

  • Кнопки +1 / +2 / +3 — бали відповідному бійцю.
  • ВІДМІНА — скасувати останній бал.
  • Голосування доступне лише коли таймер іде (стан «ГОТОВИЙ»).

3. Екран трансляції

Натисніть «ЕКРАН ТРАНСЛЯЦІЇ», введіть ID кімнати. Табло показує рахунок, час, пенальті та бали кожного судді. Кнопка ← Назад — повернення до меню.

Підрахунок

Переможець раунду визначається більшістю голосів суддів (включно з головним). Пенальті віднімаються від голосів.
